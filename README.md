# Virtual Touch

Virtual Touch is an experimental human-computer interaction system built with Python, OpenCV and MediaPipe.

The project uses a webcam to track hand and finger movements and convert them into virtual interactions, with the goal of controlling the computer through natural gestures.

## Current Features

* Real-time hand and finger tracking
* Virtual pointer controlled by the index finger
* Gesture-based interaction
* Windows mouse control
* Left and right click gestures
* Drag and scroll interactions
* Virtual objects and manipulation
* Object movement, resizing and rotation
* Two-hand interaction support
* Camera activation/deactivation
* Emergency control with ESC
* Configurable interaction and tracking parameters

## Technology

* Python
* OpenCV
* MediaPipe
* NumPy
* PyAutoGUI

## Vision

Virtual Touch is being developed as a foundation for a more advanced human-computer interaction system, combining computer vision, gesture recognition, automation and intelligent interaction.





The project is still under active development, and new interaction methods and capabilities will be added over time.
